INTERACTIVE DIVISION-AUDIT SCENARIO  (devtools/divaudit/sessions/)
====================================================================

Start:  devtools/divaudit/sessions/run_interactive.sh /tmp/divaudit/out/rich.sk
(rich.sk was produced by build_rich.py: autoshapes, arrows, dashes,
gradient fill, text, guides.  If it does not exist, run
devtools/divaudit/python2-divaudit devtools/divaudit/sessions/build_rich.py
first, or just start without a file and create objects in section B.)

Work through the sections in order; repeat each action 2-3 times.
Check off [x] as you go.  If anything crashes or looks odd, write a
one-line note next to the item and continue.  Finish with File > Quit
(needed so the audit log is flushed).  The log is
/tmp/divaudit/session-interactive.jsonl.
